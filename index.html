One project, in detail

Healthcare data · Portfolio project

Moving a monthly revenue query toward Snowflake

This repository starts with an imaginary healthcare team whose monthly revenue logic lives in a legacy query. I documented a path from legacy SQL to RAW tables, a curated view, and a BI-ready dataset.

The reconciliation script reads data/visits_legacy.csv, keeps completed visits, groups them by month and department, then compares row counts and revenue totals.

The source and target totals are calculated from the same CSV. This catches aggregation mistakes in the demo; it does not validate a live Snowflake migration.
